# 02 — Feature-wise Implementation

- **01 Dashboard** — Email Builder home, recent emails, templates, modules and fast-create actions.
- **02 Create New Email** — Setup wizard for email name, target environment, width and starting source.
- **03 Email Builder Main Workspace** — Core drag-and-drop builder with modules, canvas, properties, toolbar and live state.
- **04 Module Library** — Searchable reusable module catalog with layout/content categories and 1–6 column structures.
- **05 Layout Builder** — Column ratios, structure, mobile stacking and content order configuration.
- **06 Module Element Editor** — Edit module content, typography, spacing, image, CTA, style and advanced properties.
- **07 Responsive Editor** — Desktop/mobile side-by-side editing, stacking, alignment and mobile-specific overrides.
- **08 Asset Manager** — Upload or reference images, logos and icons; maintain alt text and reusable assets.
- **09 Code Editor** — Professional email-safe HTML editor with visual synchronization and compatibility checks.
- **10 Platform Environment** — Generic, Salesforce, Marketo, HubSpot and Pardot/Account Engagement platform adapters.
- **11 Preview Studio** — Desktop, mobile, dark mode and email-client rendering previews with provider integration hooks.
- **12 Validation Center** — Email health score, HTML/responsive/accessibility/link/image/platform checks and safe fixes.
- **13 Export Deploy** — Validated export to generic HTML or platform-specific formats and deployment hand-off.
- **14 AI Engineer Voice** — Natural-language and voice AI engineer for generation, changes, optimization and guided fixes.
