# 08 — AI Engineer & Voice

## Experience
The user presses a microphone button and speaks naturally in any supported language. No rigid command grammar. The AI receives the current email context, selected module, design tokens, platform and validation results.

## Pipeline
1. Speech-to-text / realtime audio input.
2. Intent + entity extraction.
3. Context retrieval from current email state.
4. Structured action plan.
5. Clarify if ambiguous or high-impact.
6. Preview proposed changes.
7. Apply through the command layer.
8. Validate affected regions.
9. Record reversible action history.

## Examples
- “Make every title use the brand heading style.”
- “Make these alternating sections image-first on mobile.”
- “Convert this section to two columns, 40/60.”
- “Fix only the Outlook spacing issues in this module.”

Do not require users to memorize command syntax.
