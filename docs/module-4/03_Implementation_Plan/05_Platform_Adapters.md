# 05 — Platform Adapters

Create a common capability interface rather than branching the whole builder. Example capabilities:
- personalization syntax
- dynamic content
- editable-region markup
- asset URL conventions
- scripting blocks
- export packaging
- validation rules

Adapters:
- Generic
- Salesforce Marketing Cloud
- Marketo
- HubSpot
- Pardot / Account Engagement

Platform mode should enable only the relevant controls while preserving the same document model and builder UI.
